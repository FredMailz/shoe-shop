# ShoeShop — система оформления заказов обуви

Учебный проект: десктопное приложение для просмотра каталога обуви и оформления заказов.
Текущий этап — главная форма с каталогом моделей обуви из базы данных PostgreSQL.

## Возможности

- просмотр каталога моделей обуви: изображение, категория, производство, наименование, состав, цена;
- расчёт цены со скидкой 25 % для товаров, по которым не было заказов в предыдущем календарном месяце (рядом выводится цена без скидки);
- подпись количества («много», если суммарно по всем размерам больше пяти пар, иначе «мало»);
- подсветка светло-красным цветом позиций, доступных для заказа меньше или равно трём парам;
- картинка-заглушка `resources/picture.png`, если у товара нет изображения.

Фильтрация, сортировка и поиск на текущем этапе не реализованы — они относятся к следующей задаче.

## Требования

- Python 3.10
- PostgreSQL 14
- библиотеки из файла `requirements.txt` (PyQt5, psycopg2-binary)

## Установка и запуск

1. Клонировать репозиторий:
   `git clone https://github.com/FredMailz/shoe-shop.git` и перейти в папку проекта `cd shoe-shop`
2. Создать окружение и установить зависимости:
   `python -m venv venv`, `venv\Scripts\activate` (Windows), `pip install -r requirements.txt`
3. Создать базу данных и загрузить в неё схему с данными:
   `psql -U postgres -c "CREATE DATABASE shoe_store ENCODING 'UTF8'"`
   `psql -U postgres -d shoe_store -f database/shoe_store.sql`
4. Создать файл настроек подключения:
   скопировать `config.ini.example` в `config.ini` и указать в нём хост, порт, имя базы, пользователя и пароль.
   Файл `config.ini` в репозиторий не попадает.
5. Запустить приложение: `python main.py`

## Структура репозитория

- `main.py` — точка входа приложения
- `app/` — модули приложения: `config.py` (чтение `config.ini`), `database.py` (подключение и запросы), `pricing.py` (скидка и расчётный период), `stock.py` (подписи и пороги наличия), `catalog_window.py` (главное окно)
- `resources/` — изображения товаров (`resources/images/`) и картинка-заглушка `picture.png`
- `database/` — скрипт базы данных `shoe_store.sql` (схема и данные)
- `docs/` — ER-диаграмма базы данных `er_diagram.pdf`
